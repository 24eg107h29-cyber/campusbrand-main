# CampusBrand

CampusBrand is a centralized college branding and design asset management portal. It enables campus creators, students, and faculty to discover and download approved branding materials (logos, guidelines, posters, templates, fonts, colors) while allowing administrators to upload, manage, and govern brand resources.

## Project Structure

- `Backend/`: Spring Boot 3.3.5 REST API with Spring Security (Java 17).
- `frontend/`: React 19 + Vite 7 SPA with responsive brand UI.
